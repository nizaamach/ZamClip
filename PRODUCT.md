# Product

## Register

product

## Users

Personal macOS users who repeatedly copy text, images, and files while working across apps. The primary context is a fast keyboard-driven lookup from a floating menu bar utility.

## Product Purpose

ZamClip keeps recent clipboard content available locally and lets users find and paste it without leaving the active app. Success means the user can open the palette, recognize the right item, and paste it with minimal interruption.

## Brand Personality

Quiet, native, focused. The interface should feel like a deliberate macOS utility rather than a separate dashboard application.

## Anti-references

Avoid dense dashboard layouts, decorative glassmorphism, oversized rounded cards, noisy gradients, and interactions that require pointer hunting.

## Design Principles

- Search first: the palette should be ready for typing immediately.
- Keyboard continuity: selection, preview, and paste should work without leaving the keyboard.
- Recognizable content: text, image, and file items share one result language while preserving useful type cues.
- Progressive detail: keep the result list compact and reveal richer preview only for the selected item.
- Local trust: keep privacy and missing-content states clear without interrupting the primary workflow.

## Accessibility & Inclusion

Maintain full keyboard navigation, visible selected and focused states, readable contrast, and a reduced-motion path for users who request less animation.
